# TrainerPro

Eine React-App zur Verwaltung von Trainingsplänen und Übungen für Trainer.

## Features

- Trainingspläne erstellen, bearbeiten, löschen und mit Übungen in beliebiger Reihenfolge zusammenstellen
- Übungsverwaltung (Name, Beschreibung, Ziel, Dauer, Schwierigkeitsgrad)
- Trainingsplan-Detailansicht mit Countdown-Timer pro Übung
- Statistik-Seite mit Übersicht über Pläne, Übungen und meistgenutzte Übungen
- Sportart-Auswahl in den Einstellungen

## Tech-Stack

- [React](https://react.dev/) + [Vite](https://vite.dev/)
- [Tailwind CSS](https://tailwindcss.com/) v4
- [lucide-react](https://lucide.dev/) für Icons
- shadcn/ui-artige Komponenten (Button, Card, Input) unter `src/components/ui`
